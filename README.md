# Фреймворк для взаимодействия с внутренним API платформы Visiology 3 версии v2

Данный фремворк является примером реализации методов программного взаимодействия с внутренним API платформы Visiology 3-ей версии.
Прошлая версия фреймворка, включая примеры применения для переноса сущностей между стендами старых версий платформы, перенесена в ветку **old**.

## Структура проекта

Каталог **api**
- ApiRequest.py   
  Основной класс для отправки запроса к платформе
- Core.py   
  Класс для взаимодействия с общими методами платформы, не относящимися к ее основнм компонентам

Каталог **api** **services***

- AuthService.py   
  Класс для взаимодействия с компонентом авторизации в платформе.
- DashboardService.py   
  Класс для взаимодействия с компонентом DashboardService (дашборды, регламентные отчеты).
- DataManagementService.py   
  Класс для взаимодействия с компонентом DataManagementService (загрузка данных в платформу, ETL).
- FormulaEngineService.py   
  Класс для взаимодействия с компонентом FormulaEngine (внутренняя модель данных).
- SmartForms.py   
  Класс для взаимодействия с компонентом SmartForms (модуль сбора данных).
- WorkspaceService.py  
  Класс для взаимодействия с компонентом WorkspaceService (рабочие области, пользователи, группы).
