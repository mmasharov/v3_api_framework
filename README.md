# Фреймворк для взаимодействия с внутренним API платформы Visiology 3 версии v2

Данный фремворк является примером реализации методов программного взаимодействия с внутренним API платформы Visiology 3-ей версии.
Прошлая версия фреймворка, включая примеры применения для переноса сущностей между стендами старых версий платформы, перенесена в ветку **old**.

## Структура проекта

Каталог **api**
- ApiRequest.py   
  Основной класс для отправки запроса к платформе
  - *sendRequest* Метод отправки запроса к API.
- Core.py   
  Класс для взаимодействия с общими методами платформы, не относящимися к ее основнм компонентам
  - *versionInfo* Метод получения версий компонентов платформы.

Каталог **api** / **services**

- AuthService.py   
  Класс для взаимодействия с компонентом авторизации в платформе.
  - *getBearerString* Метод получения строки с токеном авторизации.
  - *isExpired* Метод проверки срока действия токена.
- DashboardService.py   
  Класс для взаимодействия с компонентом DashboardService (дашборды, регламентные отчеты).
  - *getDSVersion* Метод получения сведений о версии DashboardService.
  - *healthCheck* Метод запроса хелсчека сервиса.
  - *getDashboards* Метод получения списка дашбордов рабочей области или метаданных определенного дашборда.
  - *createDashboard* Метод создания пустого дашборда.
  - *importDashboard* Метод импорта метаданных дашборда.
  - *getDashboardPermissions* Метод получения сведений о доступах пользователей к дашборду.
  - *exportDashboard* Метод экспорта дашборда в PDF/PNG/PPTX.
  - *getDashboardTree* Метод получения информации о ролевых доступах пользователя к рабочим областям и дашбордам.
  - *getThemes* Метод получения списка тем рабочей области или метаданных определенной темы.
  - *exportTheme* Метод экспорта пользовательской темы.
  - *importTheme* Метод импорта пользовательских тем.
  - *getUserWidgets* Метод получения списка глобальных пользовательских виджетов или сведений об определенном виджете.
  - *getWSUserWidgets* Метод получения списка пользовательских виджетов рабочей области.
  - *createUserWidget* Метод создания глобального пользовательского виджета из метаданных.
  - *createWSUserWidget* Метод создания пользовательского виджета рабочей области из метаданных.
  - *exportUserWidget* Метод экспорта пользовательского виджета.
  - *importUserWidget* Метод импорта пользовательского виджета из данных файла экспорта.
  - *getDashboardMeasures* Метод получения мер дашборда.
  - *importDashboardMeasure* Метод импорта мер на дашбордах.
  - *getWidgetDataDax* Метод получения данных виджета по его идентификатору, в формате DAX ответа от FormulaEngine.
  - *getRegularReports* Метод получения списка регламентных отчетов или сведений об отчете.
  - *getMailSchedules* Метод получения списка почтовых рассылок или сведений о рассылке.
  - *vis2Import* Метод импорта дашбордов (пользовательских тем и виджетов) из 2й версии платформы.
- DataManagementService.py   
  Класс для взаимодействия с компонентом DataManagementService (загрузка данных в платформу, ETL).
  - *getWorkspaceDatasources* Метод получения подключений JDBC рабочей области.
  - *getDatasetDatasources* Метод получения подключений JDBC набора данных.
  - *getJDBCDataLoaders* Метод получения JDBC загрузчиков данных.
  - *getTableJDBCDatasource* Метод получения подключения JDBC таблицы.
  - *importJDBCLoader* Метод импорта JDBC загрузчика (актуальный, старый dataloader/changedPassword/true/LoadJDBC находится в закомментированом блоке).
  - *refreshJDBC* Метод обновления данных нескольких JDBC-загрузчиков.
  - *refreshTable* Метод обновления данных в таблице.
  - *getExcelDataSource* Метод получения сведений об источнике данных Excel.
  - *importExcelLoader* Метод импорта данных источника Excel.
  - *getExcelMeta* Метод получения метаданных источников данных Excel из набора данных.
  - *triggerExcelUpdate* Метод обновления данных в источнике Excel.
  - *getCSVDataSource* Метод получения сведений об источнике данных CSV.
  - *importCSVLoader* Метод импорта данных источника CSV.
  - *checkOperations* Метод проверки операций над набором данных.
  - *getScheduleJobs* Метод получения заданий обновлений наборов данных рабочей области.
  - *triggerScheduledUpdate* Метод запуска запланированного обновления набора данных.
  - *getNetworkStorage* Метод получения информации о настроенных сетевых папках.
  - *getMinioLink* Метод получения ссылки на файл в хранилище minio.
- FormulaEngineService.py   
  Класс для взаимодействия с компонентом FormulaEngine (внутренняя модель данных).
  - *getDatasets* Метод получения списка наборов данных рабочей области или метаданных определенного набора.
  - *createDataset* Метод создания пустого набора данных.
  - *getDatasetPermissions* Метод получения сведений о доступах пользователей к набору данных.
  - *getDatasetRelationships* Метод получения сведений о связях в наборе данных.
  - *importDatasetRelationship* Метод импорта связей таблиц в модели данных.
  - *getDatasetMeasures* Метод получения мер из таблицы набора данных.
  - *importDatasetMeasure* Метод импорта мер в набор данных.
  - *getDatasetRoleMemberships* Метод получения пользователей назначеных в роли RLS/OLS.
  - *tableDataQuery* Метод DAX запроса данных таблицы набора данных по ее имени.
- SmartForms.py   
  Класс для взаимодействия с компонентом SmartForms (модуль сбора данных).
  - *getDimensions* Метод получения списка измерений.
  - *getDimElements* Метод получения элементов измерения.
  - *getDimFolders* Метод получения каталогов измерения.
  - *getDimLevels* Метод получения уровней измерения.
  - *getDimAttributes* Метод получения атрибутов измерения.
  - *addDimElement* Метод добавления элемента в измерение.
  - *getMeasureGroups* Метод получения списка группы показателей.
  - *getMGdescr* Метод получения описания группы показателей.
  - *getMGforms* Метод получения списка форм группы показателей.
  - *getMGformStates* Метод получения статусов формы группы показателей.
  - *getMGelements* Метод получения элементов группы показателей.
  - *addMGElements* Метод добавления элементов в группу показателей.
  - *getMGelementsDetails* Метод получения элементов группы показателей с именами измерений и их элементами.
  - *getBusinessProcesses* Метод получения списка бизнес-процессов.
- WorkspaceService.py  
  Класс для взаимодействия с компонентом WorkspaceService (рабочие области, пользователи, группы).
  - *getIdentifiers* Метод получения списка идентификаторов рабочих областей.
  - *getWorkspaces* Метод получения списка рабочих областей или сведений о рабочей области.
  - *getLicenseInfo* Метод получени сведений о лицензии.
  - *getUsers* Метод получения списка пользователей с данными об активности.
  - *getGroups* Метод получения списка групп.
  - *getGroupUsers* Метод получения пользователей групп.
  - *getRoleMappings* Метод получения сведений о пользовательских ролях.
  - *createWorkspace* Метод создания рабочей области
